# Proyecto Web: WARY

Este proyecto simula un sitio web empresarial con múltiples secciones orientadas a servicios, atención al cliente, facturación, reseñas y contacto. Fue desarrollado como parte de un trabajo académico en el curso de Desarrollo Web.

## 🧠 Objetivo

El sitio web busca representar una empresa ficticia llamada **WARY**, ofreciendo funcionalidades como:
- Página de inicio
- Servicios ofrecidos
- Clientes y reseñas
- Facturación simulada
- Libro de reclamaciones
- Login y contacto

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages (para despliegue)

## 📁 Estructura del proyecto

- `/ESTILOS`: Archivos CSS personalizados
- `/RECURSOS`: Imágenes y recursos multimedia
- `*.html`: Páginas individuales del sitio
- `*.js`: Scripts para búsqueda, validación y lógica de reseñas/facturación

## 🚀 Cómo visualizar el sitio

Puedes abrir el archivo `index.html` directamente en tu navegador o desplegar el proyecto usando GitHub Pages.
